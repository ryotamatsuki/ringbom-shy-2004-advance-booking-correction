# Stage 0 — Evidence Freeze

## Objective
Establish a self-contained, publication-grade evidentiary base before any corrected proposition is frozen.

## Required tasks
1. Freeze bibliographic identity: title, authors, journal, year, volume/issue/pages, DOI/PII where applicable.
2. Obtain and record the exact mathematical source used for every claim.
3. If the mathematical source is not the VOR, compare it with the VOR or keep an explicit VOR qualification.
4. Record hashes/identifiers for inspected source artifacts when legally available; do not commit copyrighted PDFs without permission.
5. Reconstruct the transferred discrepancy independently from primitives.
6. Re-run exact counterexamples and create permanent regression tests.
7. Search for erratum, corrigendum, comment, reply, author correction, later version, or later paper that already states the proposed correction.
8. Produce a claim-to-source evidence table and unresolved-source/version list.
9. Decide PASS / FAIL / HOLD.

## PASS conditions
- Exact source identity is frozen.
- The central discrepancy is independently reproducible.
- No unresolved source-version difference could eliminate it, or the claim is explicitly source-version qualified.
- Prior disclosure has been searched against the actual candidate claim.
- The next-stage mathematical question is narrowly falsifiable.
